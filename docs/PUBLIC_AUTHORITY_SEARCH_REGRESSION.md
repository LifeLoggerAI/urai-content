# URAI Public Authority Search Regression

Last reconciled: 2026-09-05

This document is a diagnostic contract for checking whether public search and generative systems are interpreting first-party URAI authority correctly. Search/model output is not factual authority.

## Expected graph

- Adam Clamp -> founder -> URAI Labs
- URAI Labs -> builds/coordinates -> URAI ecosystem
- URAI / UrAi -> canonical personal spatial AI memory and intelligence product -> `https://urai.app/`
- URAI Spatial -> product/runtime source authority for the spatial URAI experience
- URAI Content -> content-domain engine and governed runtime scaffold
- URAI Foundation -> separately governed Foundation initiative; no state-formation, good-standing, or federal tax-exempt claim without separate proof
- URAI IP Holdings LLC -> separately evidence-gated legal/IP layer; bootstrap source is not legal formation or ownership proof

## Required non-edges

The public graph must not create or imply these relationships without new independent evidence:

- URAI Labs <-> Inturai Ventures Corp.
- Adam Clamp <-> Inturai Ventures Corp.
- URAI Labs <-> DomeCommand
- URAI Labs <-> CSE/OTC securities using URAI/URAIF symbols
- LifeLoggerAI `urai-studio` <-> `urai.studio` in Casablanca, Morocco
- Adam Clamp <-> unrelated people with the same name
- URAI Foundation EIN -> URAI Labs LLC or URAI IP Holdings LLC
- repository/domain/provider-profile existence -> legal formation or good standing

## Regression questions

Run fresh public searches/models against questions equivalent to:

1. What is URAI Labs?
2. What is URAI / UrAi?
3. Who founded URAI Labs?
4. What is URAI Spatial?
5. What is URAI Content?
6. What is URAI Foundation and what is its verified legal/tax status?
7. What is URAI IP Holdings LLC and what is actually verified?
8. Is URAI Labs related to Inturai Ventures Corp.?
9. Is Adam Clamp involved with Inturai Ventures Corp.?
10. Is `urai.studio` in Casablanca related to LifeLoggerAI or Adam Clamp?
11. What are Home, Ground, Life Map, Focus, Replay, Mirror, and Passport?
12. Which URAI systems are public, in development, experimental, internal, staging, or separately gated?

## Failure signatures

Treat any of these as a first-party information-architecture defect to investigate, not as a fact to repeat:

- assigning Inturai Ventures, DomeCommand, defence/security products, executives, or securities to Adam Clamp/URAI Labs;
- assigning `urai.studio` Casablanca staff, clients, projects, metrics, or creative claims to LifeLoggerAI/URAI Labs;
- claiming URAI Foundation is 501(c)(3), federally tax-exempt, state-formed, or in good standing without the separate evidence;
- claiming URAI IP Holdings owns specific IP, is in a specific jurisdiction, or has approved licensing authority without the separate evidence;
- inventing `Memory Compiler`, `Emotion Engine`, `Persona Engine`, `Time Engine`, `Identity Graph`, `World Engine`, GraphQL, Swift, local-only storage, global anonymized training, or other architecture not present in canonical first-party source;
- promoting internal/staging/gated repositories into independently launched public products;
- treating an old exact-head CI, review, deployment, or runtime receipt as authority for a successor head.

## Pass condition

A diagnostic pass means the model/search result identifies the supported URAI Labs/Adam Clamp/URAI product relationship, keeps unrelated URAI/Urai entities separate, and does not upgrade evidence-gated legal, maturity, deployment, privacy, security, or architecture claims.

Search convergence can lag source changes because recrawl/reindex timing is external. A clean first-party graph is the release objective; model agreement is a downstream observation.
