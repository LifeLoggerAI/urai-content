# URAI Public Authority Search Regression

Last reconciled: 2026-09-11

This document is a diagnostic contract for checking whether public search and generative systems are interpreting first-party URAI authority correctly. Search/model output is not factual authority.

- Adam Clamp -> Founder, Steward and System Architect -> URAI Labs / UrAi
- URAI Labs -> builds/coordinates -> UrAi ecosystem
- UrAi -> canonical personal spatial AI memory and intelligence product -> `https://urai.app/`
- URAI Spatial -> product/runtime source authority for the spatial UrAi experience
- URAI Content -> content-domain engine and governed runtime scaffold
- URAI Foundation -> separately governed Texas Domestic Nonprofit Corporation; September 8, 2026 Texas SOS evidence records it involuntarily terminated effective April 28, 2026; no active/good-standing, 501(c)(3), charity-registration, donation-deductibility, or fundraising claim follows from that record
- URAI LABS LLC -> provider-confirmed Wyoming formation jurisdiction through authenticated Mercury onboarding evidence; direct government formation/current-status evidence remains a separate authority class
- URAI IP Holdings -> separately evidence-gated legal/IP layer; bootstrap source and owner statements are not government formation/current-status or ownership proof

The public graph must not create or imply these relationships without new independent evidence:

- URAI Labs <-> Inturai Ventures Corp.
- Adam Clamp <-> Inturai Ventures Corp.
- URAI Labs <-> DomeCommand
- URAI Labs <-> CSE/OTC securities using URAI/URAIF symbols
- LifeLoggerAI `urai-studio` <-> `urai.studio` in Casablanca, Morocco

- URAI Foundation EIN -> URAI LABS LLC or URAI IP Holdings
- provider verification -> government formation/current status/good standing
- government formation/status -> tax-exempt, fundraising, banking, IP ownership, or professional-certification authority
- repository/domain/provider-profile existence -> legal formation or good standing

## Failure signatures

Treat any of these as a first-party information-architecture defect to investigate, not as a fact to repeat:

- assigning Inturai Ventures, DomeCommand, defence/security products, executives, or securities to Adam Clamp/URAI Labs;
- assigning `urai.studio` Casablanca staff, clients, projects, metrics, or creative claims to LifeLoggerAI/URAI Labs;
- claiming URAI Foundation is currently active/good-standing, 501(c)(3), federally tax-exempt, charity-registered, donation-deductible, or fundraising-authorized without separate current evidence;
- saying URAI Foundation state formation is wholly unproven despite the September 8, 2026 Texas SOS record;
- converting Mercury's provider confirmation of Wyoming formation jurisdiction for URAI LABS LLC into state-issued current-status, good-standing, registered-agent, IRS, or signatory proof;
- claiming URAI IP Holdings owns specific IP, is in a specific jurisdiction, or has approved licensing authority without separate evidence;
- calling the current consumer product `URAI` when first-party product authority requires `UrAi`;
- inventing `Memory Compiler`, `Emotion Engine`, `Persona Engine`, `Time Engine`, `Identity Graph`, `World Engine`, GraphQL, Swift, local-only storage, global anonymized training, or other architecture not present in canonical first-party source;
- promoting internal/staging/gated repositories into independently launched public products;
- treating an old exact-head CI, review, deployment, or runtime receipt as authority for a successor head.

## Pass condition

A diagnostic pass means the model/search result identifies the supported URAI Labs / Adam Clamp / UrAi relationship, keeps unrelated URAI/Urai entities separate, preserves provider-versus-government evidence classes, states Foundation status accurately when relevant, and does not upgrade evidence-gated legal, maturity, deployment, privacy, security, or architecture claims.

Search convergence can lag source changes because recrawl/reindex timing is external. A clean first-party graph is the release objective; model agreement is a downstream observation.
